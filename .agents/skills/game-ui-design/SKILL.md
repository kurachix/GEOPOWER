# GEOPOWER Vintage Cartoon UI & Aesthetic Skill

This skill details how to render and style the visual interface for GEOPOWER.

## Design Principles & Aesthetic Palette

1. **Visual Style**:
   - Vintage 1930s–1970s newspaper and cartoon rubber-hose aesthetic.
   - High-contrast black ink lines, halftone dot textures, off-white newsprint background (`#f4f1ea` or `#e8e3d5`), and deep black charcoal overlays (`#1a1918`).
   - SVG filters or CSS canvas film grain overlays to emulate vintage 16mm/35mm film projection and ink press printing.

## Web Implementation (HTML, CSS, JS & Libraries)

- **Structure**: Semantic HTML5 for newsreel components, phase modal cards, and gauge indicators.
- **Styling**: Vanilla CSS3 for monochrome styling, high-contrast ink boundaries, typography, and responsive grid layouts.
- **Interactivity & Logic**: Modular JavaScript (ES6+) for DOM rendering, phase transition handlers, and sound effect triggers.
- **Libraries & Canvas Filters**:
  - HTML5 Canvas 2D / WebGL overlay for real-time film grain, flicker, and vintage paper texture rendering.
  - Web Audio API or lightweight sound libraries for mechanical clicks, press rolls, and radio noise.

---

2. **Screen Transitions**:
   - **Opening Cinematic**: 1970 Vintage Newsreel projector style, animated news headlines narrating electricity consumption boom, fuel crisis, and global summit.
   - **Player Setup Screen**: 2 to 5 player selection cards formatted like vintage passport or diplomatic credential folders.
   - **Phase Dashboards**: Analog dials, mechanical pressure gauges, toggle switches, and newspaper column event dispatches.

3. **Responsive & Interaction Tokens**:
   - Hover states with ink-splatter or rubber-hose bouncy micro-animations.
   - Mechanical button press sound cues and tactile visual feedback.
